Hand Gesture Recognition

A real-time hand gesture recognition project using Python, OpenCV and MediaPipe.

Features

- Real-time hand tracking
- Finger counting
- Pinch detection
- Fist detection
- Thumbs Up
- Pointing
- Victory
- Three fingers
- Four fingers
- Open Palm
- Call Me
- Rock gesture

Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy

Project

This project detects hand landmarks using MediaPipe and identifies gestures based on finger positions and distances between landmarks.

How to Run

1. Install the required libraries.
2. Run the Jupyter Notebook.
3. Allow camera access.
4. Show hand gestures in front of the webcam.
